# Hotel Booking Management System

### *App-Based Learning Using Core Java & Data Structures*

## 📌 Project Overview

The **Hotel Booking Management System** is a hands-on project designed to bridge the gap between academic data structure theory and real-world software engineering. By building the system incrementally, this project demonstrates how Core Java features and specific data structures solve common industry challenges like race conditions, fair scheduling, and data integrity.

## 🎯 Objectives

The primary goal is to illustrate how data structures enable robust system behavior:

* **Fair Request Handling:** Implementing FIFO (First-In, First-Out) principles to manage booking requests.
* **Inventory Consistency:** Maintaining real-time accuracy across multiple booking operations.
* **Double-Booking Prevention:** Utilizing uniqueness enforcement to ensure data integrity.
* **Scalable Design:** Transitioning from simple implementations to extensible, maintainable architectures.

---

## 🚀 Learning Approach

This project follows an **incremental development model**. Each use case introduces a single new concept, allowing you to see the "before and after" of architectural decisions.

| Feature | Focus |
| --- | --- |
| **The "Why"** | Identifying the specific business problem (e.g., "Why do we need a Queue here?"). |
| **The "What"** | Selecting the appropriate Java Collection or Data Structure to solve it. |
| **The Refactor** | Analyzing the limitations of initial designs and evolving them for production-readiness. |

---

## 🛠️ Scope & Focus

To maximize learning efficiency, this project maintains a strict focus on **Core Logic**:

* **Backend Centric:** Focuses on Object-Oriented Design (OOD) and Java Collections.
* **Minimalist UI:** User input and UI handling are kept to a minimum to avoid distracting from data structure implementation.
* **Deterministic Testing:** All interactions are console-based, ensuring high traceability and ease of debugging.

---

## 🏁 Learning Outcomes

By completing this project, you will move beyond simply knowing "how" to code in Java to understanding:

1. **Selection Criteria:** When to choose one data structure over another based on time/space complexity.
2. **System Evolution:** How production systems grow from basic scripts into robust engines.
3. **Real-World Application:** Applying abstract concepts like Uniqueness and FIFO to solve tangible business friction.
